# STASH Brand Assets

The canonical asset pack lives in [`brand/`](brand/). It is based on the
selected **Slash** identity: two rising diagonal strokes with a triangular
anchor. See [`brand/BRAND-KIT.md`](brand/BRAND-KIT.md) for the approved usage
rules, logo placement, typography, and colour guidance.

## Included
- Primary horizontal logos: SVG + transparent PNG, light/dark, 1x/2x
- Symbol/mark: SVG + PNG, gradient/light/dark/black/white
- Windows multi-size ICO and individual PNGs
- Installer icons 512/1024
- Web favicons
- PWA icons + maskable icon
- Apple touch icon
- Light/dark wordmarks
- Monochrome logos
- Light/dark high-DPI splash screens (PNG + WebP)
- 5 empty-state illustrations
- Creator home hero artwork
- 10 demo thumbnails in JPG + WebP
- Social/share preview
- Typography specification and license references

## Core colors
- Midnight: #0B1424
- Ink: #0B1020
- Electric Blue: #3B82F6
- Cyan: #38BDF8
- Violet: #7C3AED
- Canvas: #F7F9FC

## Notes
- SVG wordmarks reference Inter by family name for editability. Use the supplied PNGs when exact rendering is required without installed fonts.
- The app icon keeps generous safe padding for Windows and macOS-style presentation.
- The PWA maskable icon contains additional safe padding.
